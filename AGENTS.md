# AGENTS.md

- **Build C# scripts**: run `dotnet build` in the `godot/` folder (e.g., `dotnet build ./godot/Project.csproj`). The pre‑launch task in VS Code uses this.
- **Run the game**:
  * In Godot: open `godot/project.godot` and click **Play**.
  * From the terminal: `godot --verbose`. The Godot binary is specified by the `program` field in `.vscode/launch.json`; adjust it if your installation differs.

- **VS Code debugging**: the launch configuration (`.vscode/launch.json`) points to the Godot executable. Set the `program` field to the path of your Godot binary (Windows, Linux, macOS).
- **Namespace**: C# scripts are compiled under `murph9.RallyGame2.godot`.
- **JSON assets**: `Cars/Init/Data/*.json` are included as `Content` in the `.csproj` and copied to the output directory during build.
- **.uid files**: files ending with `.uid.cs` (e.g., `Player.uid.cs`) are generated by Godot and should not be edited.
- **.editorconfig**: formatting rules are enforced via `.editorconfig` at the repository root. Run `dotnet format` or use your editor.
- **Environment**: requires .NET 8.0 SDK and Godot 4.6.1 Mono. Verify the SDK with `dotnet --list-sdks`. Download Godot from the official site.

- **Testing**: there are no automated tests; verification is manual via the Godot editor.
- **Project layout**: everything lives under the `godot/` folder – resources, scripts, scenes, shaders, and the `Project.csproj`.
- **Common pitfalls**:
  - Forgetting to rebuild after editing C# scripts; the build task must run before launching.
  - Mixing C# and GDScript: the project currently uses only C#
