# AGENTS.md

## Overview
RallyGame2 is a Godot 4.6.1 Mono C# racing game with two modes: Pay Day (loan-paying roguelite racer) and 100km Distance (infinite road racer).

## Setup
- **Requires**: .NET 8.0 SDK (`dotnet --list-sdks`), Godot 4.6.1 Mono
- **Build**: `cd godot && dotnet build`
- **Run**: Open `godot/project.godot` in Godot editor, or `godot --verbose`

## Structure (under `godot/`)
- **Cars/** - AI, UI, init, parts
- **Component/** - Reusable components
- **GlobalState.cs** - State management
- **Hundred/** - 100km mode
- **PayDay/** - Pay Day mode
- **Utilities/** - Helpers
- **World/** - World gen
- **assets/** - Game assets
- **Shaders/** - `.gdshader` files

## Key Details
- **Namespace**: `murph9.RallyGame2.godot`
- **JSON assets**: `Cars/Init/Data/*.json` (included/copy on build)
- **.uid files**: Auto-generated by Godot, do not edit
- **Formatting**: `.editorconfig` at repo root; run `dotnet format`

## Development Notes
- No automated tests (manual verification via Godot)
- C# only (no GDScript)
- Rebuild (`dotnet build`) after C# changes before running
- Never edit `.uid` files

## Game Mechanics

**Pay Day Mode**: Pay loans/rent-to-own via racing. Collect parts (rarity: white/green/blue/purple/orange with glow shaders). Loan terms worsen daily. House furniture colors progress in 3D menu. Global unlocks: car skins, house items.

**100km Mode**: Infinite procedural road. Goals: speed traps, avg speed sections, time trials. Race traffic for money/parts. Systems: shop, NOS, tyre wear, fuel, collision damage.
